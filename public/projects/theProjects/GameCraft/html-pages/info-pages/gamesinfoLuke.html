    Description:

    Battleship game voor 2 spelers. Dit is een interactieve 2 player game gespeelt op een apparaat door het door te geven aan elkaar. Plaats je 5 schepen op een tactische positie en win!

    TECHNOLOGIEEN
    HTML 5
    CSS 3
    JS

    Rules:

    Plaats 5 schepen door te klikken op de grid, met R draai je de schepen. In de battle fase klik op de attack grid om te schieten op die positie.

    KEY FEATURES
    Custom Alerts
    schip placement
    Hit checking
